# Yasshmita Naicker — Portfolio

Svelte 5 + SvelteKit portfolio with a static production build.

## Development

Run `npm ci`, then `npm run dev`. Run `npm run check` for Svelte diagnostics and `npm run build` to generate the deployable `build/` directory.

## Content

The homepage and Global Pay case study use the supplied 2026 portfolio. Original photographs and project imagery are extracted into `static/images/` as WebP assets. The original document is available at `/yasshmita-naicker-portfolio.pdf`.

Before public launch, confirm career and education dates, supply contact details, and provide distinct content for Payments Maintenance. These are not invented in the website. The source PDF download retains its original contents, including its draft sections.

Google Fonts supplies DM Sans and Libre Caslon Display, with local system fallbacks. No analytics or form service is configured.
